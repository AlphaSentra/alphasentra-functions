Security Efficiency Metrics (1Y Rolling)

Risk-adjusted performance, volatility, and diversification metrics for each individual holding calculated over the trailing 1-year window (252 trading days).

How to interpret this:

  • Expected Return [ER] (1Y): A price-only expected-return estimate combining trend, momentum, mean-reversion, and ARIMA forecast components. A positive value signals upside momentum; negative signals downside pressure or mean-reversion drag.
  • Volatility (1Y): Annualised standard deviation of daily returns over the past year (σ × √252). Measures how much the security's price fluctuated. Lower volatility is generally preferred for a given level of return.
  • Correlation to Portfolio (1Y): Pearson correlation of the security's daily returns against the total portfolio's daily returns over the past year. Values close to 0 indicate a strong diversification benefit; values close to 1 indicate high co-movement with the overall portfolio (less diversification).
  • Composite Score (0–100): A weighted efficiency score combining all three metrics:
    • Expected Return (40% weight) — scaled from 0% (score 0) to ≥ 20% (score 1.0)
    • Volatility (30% weight) — scaled from ≥ 40% (score 0, high risk) to ≤ 5% (score 1.0, low risk)
    • Correlation (30% weight) — scaled from ≥ 0.8 (score 0, low diversification) to ≤ 0 (score 1.0, high diversification)
    0–39 — Poor efficiency 40–59 — Neutral (warm gray at 40 → cool gray at 59) 60–100 — Good efficiency

Calculation Methodology: This model uses a Price-Action Expected Return. It combines four price-derived signals: 12-month trend (current price vs. price 12 months ago), 3-month momentum (current price vs. price 3 months ago), a mean-reversion adjustment (deviation from the 200-day moving average), and a 1-step-ahead ARIMA(1,1,1) forecast. Each signal is weighted and summed to produce the expected return.

3D Rolling Portfolio Dynamics

This 3D trajectory visualizes the portfolio's evolving risk-return profile by plotting Beta, Correlation, and Alpha across 1-year rolling windows. Each data point represents a specific 1-year period, with the chronological progression indicated by a color gradient. Rotate the chart to explore how these dynamics shift over time.

How to interpret this:

  • Trajectory points: Each point represents the portfolio's beta, correlation, and alpha over a 1‑year rolling window. The color gradient shows chronological progression (earlier = cooler, later = warmer).
  • Start marker: The first point indicates the earliest window in the analysis, useful for baseline comparison.
  • Current marker: The highlighted diamond marks the most recent 1‑year window, showing today's risk‑return profile.
  • Alpha = 0 plane: The translucent surface where alpha equals zero helps separate periods of outperformance (above) from under‑performance (below).
  • Beta axis: Higher beta values imply greater market sensitivity; observe how beta moves together with correlation.
  • Correlation axis: Shows how portfolio returns co‑move with the benchmark; a rising correlation suggests convergence with market movements.
